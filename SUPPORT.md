# Support

Use GitHub Issues for project bugs, documentation gaps, and safe feature
requests. Please choose the closest issue template.

## Before Opening An Issue

- Remove personal health data, real audio, local file paths, device identifiers,
  and private screenshots.
- Use simulator, mock, or synthetic data whenever possible.
- For UI/UX reports, name the tab, screen, screenshot scenario, and what felt
  unclear.
- For privacy or licensing concerns, share only the minimum safe detail needed
  for triage.

## Not Medical Support

NightBreath is a wellness/reference project. It does not diagnose conditions,
measure clinical AHI, confirm disease, or provide treatment recommendations.
For health concerns, use qualified medical care outside this project.
