# 온보딩과 30초 캘리브레이션

NightBreath / 밤숨의 온보딩은 첫 실행 시 사용자가 개인정보 원칙, iPhone 배치, 마이크 권한, 이벤트 오디오 샘플 opt-in, 30초 캘리브레이션을 한 번에 이해하도록 돕는 흐름입니다.

## 온보딩 Flow

온보딩은 다음 단계로 구성됩니다.

- 앱 소개: 수면 소리 리포트 앱이라는 점을 설명합니다.
- 온디바이스 분석: 분석은 iPhone 안에서 수행된다는 점을 안내합니다.
- 전체 밤 오디오 미저장: 기본 동작으로 밤새 원본 오디오 전체를 저장하지 않는다는 점을 안내합니다.
- 이벤트 오디오 샘플 opt-in: 짧은 이벤트 전후 샘플 저장은 사용자가 켰을 때만 동작하며 기본값은 꺼짐입니다.
- 기기 배치 가이드: 침대 옆 탁자 또는 머리맡 근처, 마이크 막힘 방지, 충전 연결, 밀폐 위치 피하기를 안내합니다.
- 마이크 권한: 수면 소리 입력을 위해 필요한 권한임을 설명합니다.
- 30초 캘리브레이션: 주변 소음 baseline과 입력 상태를 확인합니다.

온보딩 완료 상태는 `UserSettings.hasCompletedOnboarding`에 저장됩니다. 설정 화면의 “온보딩 다시 보기” 버튼으로 완료 상태를 초기화할 수 있습니다.

## 기기 배치 가이드

권장 배치는 다음과 같습니다.

- 침대 옆 탁자 또는 머리맡 근처에 둡니다.
- 마이크가 이불, 베개, 케이스, 책 등에 막히지 않게 합니다.
- 밤새 측정을 위해 충전 연결을 권장합니다.
- 서랍, 가방, 두꺼운 책 아래, 방 반대편처럼 멀거나 밀폐된 위치는 피합니다.
- 선풍기, 가습기, 충전기처럼 지속 소음을 내는 물체와 너무 가깝지 않게 둡니다.

## 캘리브레이션 계산값

`CalibrationService`는 약 30초 분량의 `AudioChunk` 목록을 입력으로 받아 다음 값을 계산합니다.

- `ambientNoiseBaseline`: chunk RMS의 중앙값 기반 주변 소음 baseline
- `inputReceived`: 오디오 chunk가 실제로 수신되었는지 여부
- `receivedAudioSeconds`: 수신된 오디오 시간
- `audioCoverageRatio`: 목표 시간 대비 수신 시간 비율
- `recommendedPlacementMessage`: 결과에 따른 배치 안내 문구
- `calibrationQuality`: 좋음, 소음 높음, 입력 약함, 마이크 막힘 의심, 다시 시도 권장
- `averageInputLevel`: 평균 입력 수준
- `peakInputLevel`: 최대 입력 수준

`audioCoverageRatio`가 낮거나 입력 시간이 너무 짧으면 다시 시도를 권장합니다. 입력 수준이 지나치게 낮으면 iPhone 위치나 마이크 막힘을 확인하도록 안내하고, 입력 수준이 계속 높으면 주변 소음원을 멀리하도록 안내합니다.

## Simulator Mock

Simulator에서는 실제 마이크 입력 대신 `SyntheticAudioSource` 기반 mock chunk를 사용해 캘리브레이션을 실행할 수 있습니다. 이 mock은 실제 오디오 파일을 생성하지 않고, 빠르게 입력 상태 UI와 결과 표시 흐름을 확인하기 위한 개발용 동작입니다.

## 개인정보와 범위

- 서버 전송을 하지 않습니다.
- 네트워크 코드를 사용하지 않습니다.
- HealthKit 권한을 요청하거나 데이터를 읽지 않습니다.
- 전체 밤 원본 오디오 저장 기능을 추가하지 않습니다.
- 이벤트 오디오 샘플 저장은 opt-in이며 기본값은 꺼짐입니다.
- 이 기능은 수면 소리 입력 상태를 확인하기 위한 웰니스 앱 준비 단계입니다. 전문적인 건강 판단을 대신하지 않습니다.
