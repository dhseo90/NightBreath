# App Store Copy Draft

## 앱 이름

- 한국어 표시 이름: 밤숨
- English brand: NightBreath

## 부제 초안

수면 소리 리포트

## 앱 설명 초안

밤숨은 iPhone 안에서 수면 중 소리 기반 지표를 분석해 아침에 보기 쉬운 리포트로 정리하는 웰니스 앱입니다. 수면 소리 리포트에서 시작해, 앞으로 수면·혈압·체중·체성분·활동·컨디션을 함께 돌아보는 온디바이스 개인 건강 리듬 리포트 앱으로 확장합니다.

분석은 기기 안에서 수행되며 서버 전송이나 클라우드 처리를 사용하지 않습니다. 원본 전체 오디오는 저장하지 않고, 이벤트 전후의 짧은 오디오 샘플 저장도 사용자가 직접 켠 경우에만 로컬에 저장됩니다.

향후 Apple 건강앱 연결을 제공하더라도 혈압, 체중, 체성분, 심박수 같은 건강 데이터는 read-only로만 로컬 대시보드에 표시합니다. 밤숨은 HealthKit에 데이터를 쓰지 않습니다.

밤숨은 수면 소리와 건강 데이터를 더 쉽게 돌아보기 위한 참고용 앱입니다. 이 앱은 진단 목적의 의료기기가 아닙니다.

## 주요 기능

- iPhone 온디바이스 수면 소리 분석
- 수면 소리 점수와 아침 리포트
- 코골기 시간과 주요 소리 이벤트 타임라인
- 이갈이 의심 소리, 기침 의심 소리, 환경 소음, 움직임 의심 소리 표시
- 호흡정지 의심 구간과 gasp-like 회복 호흡 후보 표시
- 최근 7일/30일/90일 수면 소리 트렌드
- 향후 Apple 건강앱 read-only 방향의 혈압/체중/체성분 대시보드
- 수면 소리 지표와 건강 지표를 날짜 기준으로 함께 보는 개인 패턴 탐색 화면
- 이벤트별 사용자 피드백
- 이벤트 오디오 샘플 opt-in 저장, 재생, 삭제

## 개인정보 설명

- 서버 업로드 없음
- 클라우드 처리 없음
- 외부 분석 SDK 없음
- 광고 SDK 없음
- 계정 생성 없음
- 원본 전체 오디오 저장 없음
- 이벤트 오디오 샘플 저장 기본값 OFF
- 저장된 이벤트 오디오 샘플은 사용자가 삭제 가능
- HealthKit 데이터는 향후 read-only로만 표시
- HealthKit에 밤숨 데이터를 쓰지 않음

## 권한 설명

### 마이크

수면 중 소리 기반 지표를 iPhone 안에서 분석하기 위해 필요합니다. 원본 전체 오디오는 저장하지 않습니다.

### Apple 건강앱

향후 건강 데이터 대시보드에서 사용자가 “건강 데이터 연결”을 선택할 때만 요청합니다. 혈압, 체중, 체성분, 심박수 등 사용자가 허용한 항목을 읽어 로컬 화면에 표시합니다. 밤숨은 HealthKit에 데이터를 쓰지 않습니다.

### 이벤트 오디오 샘플

마이크 권한과 별개로, 이벤트 오디오 샘플 저장은 앱 설정에서 사용자가 직접 켠 경우에만 동작합니다. 저장되는 샘플은 이벤트 전후의 짧은 구간이며 원본 전체 오디오가 아닙니다.

## 심사 메모 초안

밤숨은 수면 소리 리포트에서 시작해 향후 Apple 건강앱 read-only sample까지 로컬에서 함께 표시하는 방향의 웰니스 앱입니다. 앱은 HealthKit에 데이터를 쓰지 않고, 서버 전송이나 외부 분석 SDK를 사용하지 않습니다. 수면 소리 분석 결과는 참고용 지표이며 앱 안에서도 진단 목적의 의료기기가 아니라는 안내를 제공합니다.
