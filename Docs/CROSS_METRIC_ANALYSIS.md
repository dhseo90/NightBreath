# 수면 소리 × 건강 지표 교차 보기

이 문서는 NightBreath / 밤숨 앱에서 로컬 수면 소리 리포트와 mock 또는 HealthKit read-only 건강 sample을 함께 표시하는 개발 기준을 설명합니다.

## 목적

- 수면 소리 점수, 코골기 시간, 이갈이 의심 소리, 호흡정지 의심 구간, 기침 의심 소리, 환경 소음, 오디오 커버리지를 건강 지표와 날짜 기준으로 나란히 봅니다.
- 건강 지표는 수축기 혈압, 이완기 혈압, 체중, 체지방률, BMI, 안정시 심박수를 우선 지원합니다.
- 이 화면은 개인 패턴을 살펴보기 위한 참고용 보기입니다. 인과관계를 의미하지 않습니다.
- “코골기 시간이 긴 날과 다음날 혈압 데이터를 함께 표시합니다.”처럼 관찰 중심으로 표현합니다.

## 날짜 매칭

수면 리포트의 기준 날짜는 `NightReport.generatedAt`의 달력 날짜입니다.

- 혈압: 수면 리포트 날짜 다음날 04:00부터 12:00까지의 혈압 sample을 찾습니다.
- 체중/체지방률/BMI/안정시 심박수: 수면 리포트와 같은 날짜의 sample을 찾습니다.
- 같은 window에 여러 sample이 있으면 가장 이른 sample을 사용합니다.
- 기간 선택은 7일, 30일, 90일입니다.
- UI는 scatter chart와 날짜별 매칭 목록을 함께 표시합니다.
- 날짜별 매칭 목록에는 수면 리포트 날짜, 건강 sample 측정 시각, sourceName, 오디오 커버리지를 표시합니다.

## 데이터 부족 기준

- 매칭되어 요약에 사용할 수 있는 sample이 3개 미만이면 분석 요약을 표시하지 않습니다.
- 이 경우 화면에는 “비교 가능한 데이터가 아직 부족합니다.” 안내를 표시합니다.
- 건강 데이터 권한이 없거나 데이터가 비어 있어도 기존 수면 소리 기능은 그대로 동작합니다.
- 데이터가 부족한 경우에는 추세나 패턴 요약을 생성하지 않습니다.

## 낮은 측정 품질 처리

- 수면 리포트의 `audioCoverageRatio`가 0.85 미만이거나 `measurementQuality`가 `limited`/`poor`이면 요약 계산에서 제외합니다.
- 제외된 점은 그래프에서 별도로 구분해 표시합니다.
- 이렇게 처리하는 이유는 오디오 입력이 충분하지 않은 날의 수면 소리 지표가 비교 기준으로 불안정할 수 있기 때문입니다.

## 개인정보와 HealthKit 방향

- 모든 계산은 기기 안에서만 수행합니다.
- 서버 전송, 클라우드 처리, 외부 분석 SDK를 사용하지 않습니다.
- HealthKit 데이터는 read-only로만 읽습니다.
- preview와 테스트에서는 mock service/protocol 기반 sample을 사용할 수 있습니다.
- 앱은 HealthKit에 수면 소리 점수나 건강 데이터를 쓰지 않습니다.
- sourceName/sourceBundleIdentifier를 표시해 사용자가 Apple 건강앱 내 데이터 출처를 확인할 수 있게 합니다.

## 해석 한계

- 이 화면은 전문적인 건강 판단을 위한 기능이 아닙니다.
- 수면 소리 지표와 건강 지표가 같은 날짜 근처에 함께 표시되어도 인과관계를 뜻하지 않습니다.
- 혈압과 체성분 수치에 대한 건강 상태 결론을 제공하지 않습니다.
- 실제 생활 패턴, 측정 시간, 기기 배치, 오디오 커버리지, HealthKit source별 기록 방식에 따라 결과가 달라질 수 있습니다.
