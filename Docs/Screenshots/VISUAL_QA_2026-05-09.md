## 실제 iPhone Visual QA

simulator에서 선검증한 파일:

- `Docs/Screenshots/AppStore/raw/01_home_dashboard_light.png`
- `Docs/Screenshots/Privacy/cropped/calibration_light.png`
- `Docs/Screenshots/EdgeStates/cropped/event_audio_storage_off_light.png`

실제 iPhone preflight:

- 연결된 iPhone 대상 Debug build 성공
- Debug app install 성공
- `devicectl device process launch`와 DEBUG screenshot scenario argument로 주요 화면을 직접 실행했습니다.
- iPhone Mirroring 화면 캡처 기준으로 홈, 수면 시작, 수면 기록 중, 건강 데이터, Fitdays 가져오기, Fitdays 결과, 아침 리포트, 오늘의 리듬, 하루 리듬 카드, 카드 export, 개인정보, 이벤트 오디오 저장 꺼짐, 캘리브레이션, Health permission empty, report empty 화면을 확인했습니다.

수정/판정:

- 홈 화면은 launch 직후 score header가 사라진 것처럼 보이는 초기 scroll offset 문제가 있었고, `ScrollViewReader` top anchor로 수정했습니다.
- 하단 tab bar는 실제 iPhone에서 content가 비쳐 보였고, opaque `UITabBarAppearance`와 `floatingTabBarAvoidance` 72pt 조정으로 수정했습니다.
- Calibration 화면은 title, 입력 상태 card, 시작 button이 실제 iPhone viewport에서 겹침 없이 보입니다.
- Event audio storage off 화면은 OFF 상태, 0개/0초/0B, local-only/privacy copy가 실제 iPhone viewport에서 읽힙니다.

아직 남은 실기기 확인:

- 실제 마이크 입력, foreground/background 전환, 화면 잠금, overnight 측정, 배터리/발열은 실행하지 않았습니다.
- 실제 HealthKit 권한 조합 선택, 실제 Health 데이터 표시, 실제 Fitdays 앱 export/share flow는 실행하지 않았습니다.
- iPhone Mirroring 클릭/스크롤 제어는 Computer Use의 `noWindowsAvailable` 오류로 직접 조작하지 못했고, DEBUG launch scenario로 대체했습니다.

## Privacy / Release Notes

- 실제 개인 건강 데이터, 실제 Fitdays CSV, 실제 오디오 파일, 실제 이벤트 오디오 샘플은 사용하지 않았습니다.
- HealthKit write, 서버 전송, 외부 API/SDK 추가는 없습니다.
- DEBUG scenario는 DEBUG 빌드 검증용이며 Release 빌드 user-facing surface에 노출되면 안 됩니다.
