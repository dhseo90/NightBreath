## 노출 정책

- `sleepFinalizingSlow`, `healthRefreshStates`, `debugAudioSamplesFixture`는 DEBUG-only 검수 화면입니다.
- `privacySnapshot`은 release behavior를 확인하기 위한 DEBUG capture route이며, README/App Store marketing surface에는 바로 렌더링하지 않습니다.
- 임시 PNG는 visual QA evidence로만 사용하고 repository에는 포함하지 않습니다. 정식 재캡처 4개는 screenshot manifest에 등록합니다.
- 실제 개인 건강 데이터, 실제 Fitdays CSV 파일명, 실제 오디오 파일명, 실제 이벤트 오디오 샘플은 사용하지 않았습니다.
- 서버 전송, HealthKit write, 외부 API/SDK 추가는 없습니다.
